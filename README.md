# API Port de Russel

Application de gestion de catways, réservations et utilisateurs.

## Technologies

- Node.js
- Express
- MongoDB
- Mongoose
- EJS
- JWT
- Bcrypt

## Installation

<code>
```bash
npm install
npm start
</code>

## Variables d'environnement

### Créer un fichier .env :

    MONGO_URI=...
    JWT_SECRET=...

## Accès

- Admin : via création en base
- Utilisateur : inscription

## Fonctionnalités 

- Authentification sécurisée
- Gestion catways
- Gestion réservations
- Dashboard dynamique
- Profil utilisateur
- API REST
- Sécurité
- JWT
- Password hashé
- Routes protégées
- Variables environnement
